## Vendor content — what this repository does NOT ship

This repository contains no copyrighted game content: no original game
binaries, no .cob/.shp/.fnt data, no audio, no vendor text files, no saves.
The engine reads game data only from a copy of the original distribution
that the user supplies locally (see README, "Supply your own game data").
All findings about the original formats in docs/ are clean-room measurement
records derived from a lawfully held copy, quoted at lengths we consider
fair use.

"Abandonware" describes how the original is informally circulated; it is not
a license. Rights in the original Ascendancy game and its assets remain with
their respective owners. Publisher-side rights (Virgin Interactive /
Broderbund / Softgold per the game's publication history) may sit with
parties other than the developers addressed above; the developer grant offer
above covers OUR code only, never theirs, and asserts nothing about
publisher rights.
