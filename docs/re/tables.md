field, NOT a record count. Its meaning is unresolved.

### 3a. Shared string block across all 7 `.tsv`

A 40-byte run starting at `species.tsv` offset 182:
```
b'Orbital Structures\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00'
```
occurs in:
  - battle.tsv: [182]
  - beginnew.tsv: [182]
  - galactic.tsv: [182]
  - planet.tsv: [182]
  - ship.tsv: [182]
  - species.tsv: [182]
  - tutintro.tsv: [182]
and in NONE of the 7 `.bin` files. So the `.tsv` carry display strings
(tech names, screen/form labels) that the `.bin` tables do not. This is
the strongest available lead on what a `.tsv` is; still unconfirmed.
