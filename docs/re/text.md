## 1. Encoding [verified — whole family]

High bytes (>0x7F) actually used: **1** distinct.

| byte | count | CP437 | CP1252 | first occurrence |
|---|---|---|---|---|
| 0xcd | 5884 | ═ | Í | `end-capt.txt` +71 |

The single high byte is the CP437 box-drawing character used in comment
rules (`//═══…`). Under CP1252 the same byte renders as 'Í', which is
nonsense in context — so **CP437 is the corpus encoding** and the importer
must decode with cp437, not latin-1 or cp1252. No 128-row conversion table
is needed for ascend00; a 128-entry table would be dead weight.
