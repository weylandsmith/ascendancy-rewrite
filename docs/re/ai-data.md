# P2-input — per-race AI parameters and diplomacy actions (data-driven)

Generated by `scripts/dip_probe.py`. Sources: `extracted/ascend00/race00..20.dip` (21 files, from `ascend00.cob`).

## 1. File grammar [verified 21/21]

```
  <comment preamble>            free text, CRLF, cp437
  DIPVALUES                     section marker (uppercase, own line)
  KEY <int>                     15 keys, identical set in all 21 files
  ACTIONS                       section marker
  DA_<Name>\n<body text>        15 tokens; body runs to next DA_ or marker
```

The file's own preamble states the rule: "Everything above the upper-case
'dipvalues' below is comments." [verified: race00.dip line 3]

Key-set identity across races: 1 distinct DIPVALUES key set over 21 files (15 keys); 2 distinct ACTION token sets (section 4). Because the numeric SHAPE is constant and only VALUES differ, per-race AI personality is **data-driven**, which closes OQ-009.

## 4. ACTION tokens

15 diplomacy action identifiers exist across the corpus, but the
sets are NOT identical: 4 files (races 00, 02, 13, 19) carry all of them; the other
17 lack `DA_BreakAlliance` while still carrying `DA_BreakAllianceWithOtherRace`.
A loader that demands a body for every token would fail on 17 of 21 races, so the
missing token must be treated as optional. [verified, per-token coverage below]

| token | races providing a body (of 21) |
|---|---|
| `DA_BreakAlliance` | 4 |
| `DA_BreakAllianceWithOtherRace` | 21 |
| `DA_DeclareWar` | 21 |
| `DA_DeclareWarOnOtherRace` | 21 |
| `DA_Discover` | 21 |
| `DA_DiscoverAskHelp` | 21 |
| `DA_HelpControlSystem` | 21 |
| `DA_NoDipAction` | 21 |
| `DA_OfferPeace` | 21 |
| `DA_OfferPeaceToOtherRace` | 21 |
| `DA_ProposeAlliance` | 21 |
| `DA_ProposeAllianceToOtherRace` | 21 |
| `DA_TradeResearch` | 21 |
| `DA_TradeStarlanes` | 21 |
| `DA_TradeStars` | 21 |

- `DA_BreakAlliance` — race00 text: %y are no longer of value as allies.  We are terminating alliance.
- `DA_BreakAllianceWithOtherRace` — race00 text: We request termination of alliance between %y and %t.
- `DA_DeclareWar` — race00 text: Peace state is over.  We are entering war state with %y.
- `DA_DeclareWarOnOtherRace` — race00 text: We request declaration of war by %y on %t.
- `DA_Discover` — race00 text: %y species.  We are %m.
- `DA_DiscoverAskHelp` — race00 text: We request immediate military aid.  %s system.
- `DA_HelpControlSystem` — race00 text: We request assistance of %y in control of %s system.
- `DA_NoDipAction` — race00 text: Awaiting transmission from %y.
- `DA_OfferPeace` — race00 text: War with %y has no value to us.  We request armistice.
- `DA_OfferPeaceToOtherRace` — race00 text: We are inhibited by war between %y and %t.  We request peace offer to %t.
- `DA_ProposeAlliance` — race00 text: We propose alliance with %y.
- `DA_ProposeAllianceToOtherRace` — race00 text: We request offer of alliance by %y to %t.
- `DA_TradeResearch` — race00 text: We require technology.  We request research trade.
- `DA_TradeStarlanes` — race00 text: We need star lane knowledge.  We request trade.
- `DA_TradeStars` — race00 text: We have visited too few stars.  We request star information trade.
